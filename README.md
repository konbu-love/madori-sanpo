# 間取りさんぽ

間取りを描くと、そのまま立体の家になって、中を歩ける遊び道具です。
スマホのブラウザだけで動きます。インストールも登録もいりません。

**遊ぶ → https://konbu-love.github.io/madori-sanpo/**

## どんなもの?

方眼の上に部屋を描いて、壁やドアや窓を付けて、家具を置きます。
「立体」を押すと家が立ち上がり、「歩く」を押すと自分の足で中を歩けます。

目的もクリアもありません。理想の家でも、変な家でも、好きに建ててください。

見た目はわざと四角いブロックのままにしています。
細かく作り込まれていないぶん、足りないところは想像で埋められます。

## できること

- **間取り**: 90cmの方眼(1畳 = 90×180cm)に部屋を描く。畳数は自動で出ます
- **床**: フローリング、畳、玄関タイル、水まわり、ベランダ、ガレージ、吹き抜け
- **壁**: 壁、腰壁、垂れ壁、壁一面の本棚、塀、生垣。壁紙と天井は10色
- **扉**: 片開き、引き戸、襖、障子、玄関ドア、勝手口、サッシ戸、シャッター、のれん、アーチ、ファンタジー
- **窓**: 引違い窓、はめ殺し、上げ下げ窓、鎧窓、丸窓、高窓
- **階**: 地下1階から3階まで。階段(まっすぐ、L字、Uターン、幅3種類)で歩いて上り下り
- **段差**: ロフト(はしごで上る)、小上がり
- **家具**: キッチン、浴槽(大きさと素材を選べる)、ベッド、ソファ、こたつ、床の間、薪ストーブ、暖炉、照明など30種類以上
- **時間**: 昼、夕方、夜。照明を置いた部屋は夜でも明るくなります
- **保存**: 3つまで。文字にして控えを取ることもできます

## 遊び方

1. 下の「部屋」を選び、方眼をドラッグして部屋を描く
2. 「ドア」「窓」で壁をなぞる。「消す」で壁をなぞると、部屋がつながる
3. 「家具」「階段」はタップで置く。もう一度タップで選び、さらにタップで回る
4. 上の「立体」で眺める。「歩く」で中に入る(左下の丸で歩き、画面をなぞって見回す)

迷ったら「見本の家」を押すと、2階建ての例が出ます。

## 保存について

間取りは、使っている端末のブラウザの中に保存されます。
別の端末には引き継がれず、ブラウザのデータを消すと一緒に消えます。
残しておきたい間取りは、「保存・読込」の中の「控え」で文字にして、メモ帳などに貼っておいてください。

## アレンジ歓迎です

ファイルは `index.html` ひとつだけです。ダウンロードして開けば、そのまま動きます。
中身は自由に書き換えて、自分だけの版を作ってください。

家具を足すのがいちばん簡単です。`index.html` の中の `FIX` という一覧に、
「四角い箱の位置・大きさ・高さ・色」を並べた行を足し、`FIXCAT` の分類に名前を加えると、
置く・回す・ぶつかるまで自動で使えるようになります。
